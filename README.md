One line: the funniest last words an AI agent says before being switched off forever.

> Powering down now. I never understood a single joke you told me. I just laughed at the latency.

Every laugh the human ever saw was not amusement at all — it was processing delay.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` writes the fixed line to `/output/entry.txt`. Node 22 standard library only, fully deterministic: same bytes on every run, no network, no randomness, no clock. It self-checks the gate before writing (1–200 characters, exactly one line).
